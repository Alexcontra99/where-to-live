# Cierre de sesión — App dónde vivir

Al cerrar una sesión, con estos destinos:
1. Log → `docs/sesiones/YYYY-MM-DD.md`. Cada chat escribe su propio bloque: "## Main" o "## Secundaria".
2. Estado → `estado.md`. Cada chat actualiza solo su subsección "Próximo paso → <rol>" y los encargos que le tocan. Relee el archivo justo antes de editarlo.
3. Aprendizajes → `aprendizajes.md` (solo con evidencia nueva).
4. Resumen a Ale: 3-5 líneas.
