# Cierre de sesión

1. Log → `sesiones/YYYY-MM-DD.md`. Cada chat escribe su propio bloque: "## Main" o "## Secundaria". Sin datos personales: el log se sube.
2. Estado → `estado.md`. Cada chat actualiza solo su subsección "Próximo paso → <rol>" y los encargos que le tocan. Relee el archivo justo antes de editarlo. El "Próximo paso" debe poder seguirlo un chat nuevo sin preguntar: qué hacer, con qué archivo y qué falta de las personas.
3. Aprendizajes → `aprendizajes.md` (solo con evidencia nueva).
4. Git → rama + pull request, nunca commit directo a `main` (`CONTRIBUTING.md`).
5. Resumen: 3-5 líneas (qué se hizo, problemas, siguiente paso).
